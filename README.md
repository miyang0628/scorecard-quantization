# scorecard-quantization

Reproducible simulation study for **"Quantization of Additive Lattice Scorecards:
Perturbation Bounds for Probability, Ranking and Band Stability."**

An additive scorecard assigns a real-valued log-odds contribution to each binned
attribute and sums them; for deployment these contributions are rounded onto a
common integer points grid. This repository numerically validates a perturbation
theory for that deployment-time rounding, showing how the error propagates through
three functionals of increasing operational sensitivity — the predicted
**probability**, the induced **ranking** (AUC), and a **band assignment** into `K`
grades — and establishing a *separation* phenomenon: grade stability degrades while
ranking stays robust at the same lattice spacing.

All deployment dials (the points-to-double-the-odds scale `PDO` and the rounding
grid `g`) enter through a single parameter, the **effective log-odds lattice
spacing** `Δ = g·ln2 / PDO`. Every experiment below is a statement about `Δ`.

## What is validated

| Notebook | Result | Claim checked |
|---|---|---|
| `01_probability_error` | Theorem 1 | worst case `max|e| ≤ PΔ/2`; typical scale `std(e) ≈ Δ√(P/12)`; probability error attenuated by `p(1−p)` |
| `02_ranking_stability` | Theorem 2 + corollary | AUC loss is `O(Δ)` and small; higher discrimination buys greater robustness |
| `03_band_migration` | Theorem 3 | migration rate is linear in band count `K` and in `Δ` |
| `04_separation_theorem` | Theorem 4 | migration/reversal ratio grows like `Θ(K)`; a window exists where AUC loss ≈ 0 but a sizeable share migrate grade |
| `05_tightness_monotonicity` | Propositions | worst-case bound is attained; distinct integer scores scale like `W/Δ`; monotonicity in `Δ` |
| `06_robustness` | robustness battery | scaling exponents in `Δ`; sensitivity to feature count `P`; banding scheme (equal-frequency / equal-width / modes); genericity of the `Δ√(P/12)` law across 30 random populations |
| `07_geometric_factor` | Proposition (closed form) | validates `φ_m(0)=∫ρ₊ρ₋`, the migration closed form `M=(Σρ(q_k))E|e|`, the ratio law `M/R≈(K-1)ρ̄/φ_m(0)`, and the saturation crossover `K*≈W/E|e|` |
| `08_ablation` | ablation | the two dials `(PDO, g)` collapse exactly onto `Δ=g·ln2/PDO`; round-to-nearest is unbiased while truncation biases by `-PΔ/2`; the `√P` law is robust (±20%) to cross-feature correlation |
| `09_real_data` | external validation | all four levels and the closed form `φ_m(0)=∫ρ₊ρ₋` hold on a real, non-credit dataset (scikit-learn breast cancer, offline) |

Data are **synthetic** (a reproducible additive-scorecard population generated by
`00_generate_synthetic_data`); no external or proprietary data are used.

## Reproducing the results

Requires Python ≥ 3.10.

```bash
pip install -r requirements.txt

# run notebooks in order; notebook 00 writes data/ that the others load
jupyter nbconvert --to notebook --execute --inplace notebooks/00_generate_synthetic_data.ipynb
jupyter nbconvert --to notebook --execute --inplace notebooks/01_probability_error.ipynb
jupyter nbconvert --to notebook --execute --inplace notebooks/02_ranking_stability.ipynb
jupyter nbconvert --to notebook --execute --inplace notebooks/03_band_migration.ipynb
jupyter nbconvert --to notebook --execute --inplace notebooks/04_separation_theorem.ipynb
jupyter nbconvert --to notebook --execute --inplace notebooks/05_tightness_monotonicity.ipynb
```

Or open them in Jupyter and run the single cell in each. The random seed is fixed
in notebook 00 (`20251110`), so the generated population and every downstream
figure and table are deterministic.

## Representative output

With a synthetic population of `N=20000`, `P=20` features and base rate ≈ 8%
(continuous-score AUC ≈ 0.87):

- `std(e) ≈ Δ√(P/12)` matches to ~2 significant figures across the `Δ` grid.
- AUC loss stays below 0.003 up to `Δ=0.2` while band migration (K=10) already
  reaches ~30% — the separation window.
- the migration/reversal ratio at `Δ=0.1` rises `7.8 → 11.0 → 16.1 → 33.1` for
  `K = 5, 7, 10, 20`, i.e. linear in `K`.

## Relation to the companion paper

This repository accompanies a **theory** paper on scorecard quantization. A
separate, **empirical** study — distilling a tabular foundation model into an
additive scorecard and analysing calibration transfer on real credit portfolios —
is reported elsewhere and is **not** reproduced here. This repository shares only
the object "lattice-quantized additive scorecard"; it reuses none of that study's
experiments, datasets, or results.
